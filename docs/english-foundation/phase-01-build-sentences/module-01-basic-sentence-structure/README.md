# Module 1 — Basic Sentence Structure

## Mục tiêu

Người học nhận biết và tạo được câu đơn với các mẫu `S + V`, `S + V + O`, `S + be + Noun` và `S + be + Adjective`. Giới thiệu `be` ở mức dùng trong câu; Module 3 sẽ đi sâu hơn.

## Thứ tự bài học

1. [A Complete Sentence](01-a-complete-sentence.md) — nhận biết câu hoàn chỉnh.
2. [Subject + Verb](02-subject-verb.md) — tạo câu `S + V`.
3. [Subject + Verb + Object](03-subject-verb-object.md) — thêm đối tượng.
4. [Subject + be + Noun](04-subject-be-noun.md) — giới thiệu danh tính hoặc nghề nghiệp.
5. [Subject + be + Adjective](05-subject-be-adjective.md) — mô tả trạng thái.
6. [Mini Checkpoint](06-mini-checkpoint.md) — kết hợp các mẫu đã học.

## Cách học

Mỗi lesson có lý thuyết ngắn bằng tiếng Việt và 12 câu luyện tập; checkpoint có 30 câu. Các bài đều có hoạt động nghe qua Sound of Text và phần ôn lại. Bài checkpoint giúp tự kiểm tra các mẫu trước khi học tiếp. Người học tự đánh dấu hoàn thành.

Nội dung Markdown là nguồn biên soạn; cần nhập catalog vào Turso trước khi dùng ở môi trường thật.
