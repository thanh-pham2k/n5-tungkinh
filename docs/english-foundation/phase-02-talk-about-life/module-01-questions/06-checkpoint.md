# Mini Checkpoint — Questions

## 1. Mục tiêu

Tổng ôn toàn bộ các dạng câu hỏi cơ bản: câu hỏi Yes/No với to be (*Am/Is/Are*), câu hỏi Yes/No với trợ động từ (*Do/Does*), câu hỏi Wh- với *What, Where, Who, When, Why* và các cụm câu hỏi với *How*.

Bộ đề gồm 30 câu: **15 câu trắc nghiệm**, **10 câu sắp xếp từ** và **5 câu gõ phím**.

## 3. Áp dụng

Nghe và thực hành câu hỏi giao tiếp cơ bản:

> **Where do you live?**

`audio:en|Where do you live?`

*Tự đối chiếu:* **Where** + **do you live?**

## 4. Ôn lại

- Câu hỏi Yes/No: đảo *to be* lên đầu hoặc dùng trợ động từ *Do/Does*.
- Câu hỏi Wh-: **Từ để hỏi + to be / do / does + S + V?**
- Ghi nhớ: *What* (gì), *Where* (ở đâu), *Who* (ai), *When* (khi nào), *Why* (tại sao), *How* (thế nào).
- Bấm **Đánh dấu hoàn thành** để ghi nhận kết quả.
