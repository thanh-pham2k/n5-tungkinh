## 10.2. So sánh tính từ — Le comparatif

### Lý thuyết

So sánh đặc điểm của hai người, vật hoặc địa điểm.

**Cấu trúc:** `plus / moins / aussi + adjectif + que`

| Cấu trúc | Nghĩa | Ví dụ |
| --- | --- | --- |
| plus... que | Hơn | plus calme que |
| moins... que | Kém hơn | moins cher que |
| aussi... que | Ngang bằng | aussi confortable que |

Ví dụ:

- Le vélo est plus pratique que la voiture. — Xe đạp tiện lợi hơn ô tô.
- Ce studio est moins lumineux que cet appartement. — Studio này ít sáng hơn căn hộ kia.
- Ma maison est aussi grande que la tienne. — Nhà tôi lớn bằng nhà bạn.

**Lưu ý:** Tính từ vẫn hòa hợp với chủ ngữ.

- Il est plus sportif.
- Elle est plus sportive.
- Elles sont plus sportives.

## 10.3. So sánh số lượng và dạng bất quy tắc

### So sánh danh từ

**Cấu trúc:** `plus de / moins de / autant de + nom + que`

| Cấu trúc | Nghĩa |
| --- | --- |
| plus de... que | Nhiều hơn |
| moins de... que | Ít hơn |
| autant de... que | Nhiều bằng |

Ví dụ:

- Le vélo fait moins de bruit que la voiture. — Xe đạp ít gây tiếng ồn hơn ô tô.
- Il y a plus de pollution qu'avant. — Ô nhiễm nhiều hơn trước.
- Notre appartement a autant de pièces que le vôtre. — Hai căn hộ có số phòng bằng nhau.

### So sánh bất quy tắc

| Từ gốc | So sánh hơn |
| --- | --- |
| bon | meilleur |
| bonne | meilleure |
| bons | meilleurs |
| bonnes | meilleures |
| bien | mieux |

- La qualité de vie est meilleure. — Chất lượng sống tốt hơn.
- Cet appartement est mieux situé. — Căn hộ này có vị trí tốt hơn.

**Lỗi thường gặp:** Không dùng `plus bon` hoặc `plus bien` trong các phép so sánh thông thường này.

## 10.4. Đại từ sở hữu — Les pronoms possessifs

### Lý thuyết

Đại từ sở hữu thay thế danh từ đi kèm tính từ sở hữu.

`Mon vélo → le mien`

— Je peux prendre ton vélo ?

— Je peux prendre le tien ?

### Bảng đại từ sở hữu

| Người sở hữu | Đực ít | Cái ít | Đực nhiều | Cái nhiều |
| --- | --- | --- | --- | --- |
| Je | le mien | la mienne | les miens | les miennes |
| Tu | le tien | la tienne | les tiens | les tiennes |
| Il / Elle | le sien | la sienne | les siens | les siennes |
| Nous | le nôtre | la nôtre | les nôtres | les nôtres |
| Vous | le vôtre | la vôtre | les vôtres | les vôtres |
| Ils / Elles | le leur | la leur | les leurs | les leurs |

### Ví dụ

- Ma voiture → la mienne.
- Tes skis → les tiens.
- Ses chaussures → les siennes.
- Notre maison → la nôtre.
- Vos enfants → les vôtres.
- Leur appartement → le leur.

**Lưu ý:** Giống và số phụ thuộc vào vật được sở hữu, không phụ thuộc vào giới tính người sở hữu.

## 10.5. Phát âm — Les sons [o], [ɔ], [ø], [œ]

| Âm | Đặc điểm | Ví dụ |
| --- | --- | --- |
| /o/ | Âm o khép | vélo, bateau, auto |
| /ɔ/ | Âm o mở | pomme, port |
| /ø/ | Âm eu khép | feu, peu, mieux, queue |
| /œ/ | Âm eu mở | fleur, cœur, peur, moteur, meilleur, leur, pleurs |

Luyện đọc: `vélo – pomme – feu – fleur`.

## Tóm tắt — TL;DR

| Kiến thức | Cấu trúc |
| --- | --- |
| So sánh hơn | plus + adjectif + que |
| So sánh kém | moins + adjectif + que |
| So sánh bằng | aussi + adjectif + que |
| Số lượng nhiều hơn | plus de + nom + que |
| Số lượng ít hơn | moins de + nom + que |
| Số lượng bằng nhau | autant de + nom + que |
| Bon → meilleur | Une meilleure qualité de vie. |
| Bien → mieux | Un appartement mieux situé. |
| Đại từ sở hữu | le mien, la tienne, les siens... |

**Ghi nhớ:** Dùng `aussi` khi so sánh tính từ, `autant de` khi so sánh số lượng. Đại từ sở hữu phải phù hợp với người sở hữu, giống và số của danh từ được thay thế.
