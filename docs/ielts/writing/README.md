# Luyện IELTS Academic Writing

Đích học: **Academic Task 1 và Task 2**, theo lựa chọn của người dùng ngày 2026-10-11.

- `Writing_Practice.md` → Writing Review trên n5-tungkinh.
- Mỗi ngày đặt heading `### YYYY-MM-DD`; CSV có 4 cột: `context,prompt,input,sample_answer`.
- Bắt đầu bằng các phần nhỏ: Task 1 introduction / overview / details; Task 2 introduction / body / conclusion. Các mẫu hiện tại là bài luyện từng phần.
- Tự viết trước, xem mẫu sau, kiểm tra có trả lời đúng yêu cầu và phát triển ý rõ không. Writing Review chỉ ghi nhận câu trả lời và hiện mẫu; chưa chấm band hoặc sửa ngữ pháp tự động.
- Bài Task 1 có số liệu trong phần Input; không suy đoán dữ liệu ngoài đề.

Cập nhật nguồn ở đây rồi chạy `node scripts/sync-n5.mjs E:/n5-tungkinh`. Không sửa tay dữ liệu JS được sinh ở repo đích. Chưa dùng dấu phẩy bên trong ô CSV vì script đồng bộ hiện kiểm tra bằng dấu phân cách đơn giản.
